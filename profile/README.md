# EffortlessMetrics

Verification infrastructure for agentic development.

---

## Verification Tooling

| Repo | What it does |
|------|-------------|
| [ripr](https://github.com/EffortlessMetrics/ripr) | Static mutation exposure analysis for Rust. Experimental Python and TypeScript in development |
| [unsafe-review](https://github.com/EffortlessMetrics/unsafe-review) | Static unsafe contract coverage for Rust PRs |
| [cargo-allow](https://github.com/EffortlessMetrics/cargo-allow) | Source exception ledger for Rust repositories |
| [ub-review](https://github.com/EffortlessMetrics/ub-review) | Targeted CI gate with review judgment built in |

## Parser Infrastructure

| Repo | What it does |
|------|-------------|
| [perl-lsp](https://github.com/EffortlessMetrics/perl-lsp) | Perl 5 language server that parses Perl without running Perl. 925k lines of Rust. Built-in in Red Hat's LSP4IJ for JetBrains and Eclipse |
| [tokmd](https://github.com/EffortlessMetrics/tokmd) | Deterministic repository receipts, review artifacts, and CI gates |

## Real-Time Hardware

| Repo | What it does |
|------|-------------|
| [OpenRacing](https://github.com/EffortlessMetrics/OpenRacing) | 1kHz force-feedback and telemetry stack for sim racing wheels. 1.1M lines of Rust |
| [OpenFlight](https://github.com/EffortlessMetrics/OpenFlight) | 250 Hz force-feedback and telemetry stack for flight simulators. 0.5M lines of Rust |

## Legacy and Regulated Data

| Repo | What it does |
|------|-------------|
| [copybook-rs](https://github.com/EffortlessMetrics/copybook-rs) | COBOL copybooks to JSON and Parquet |
| [pst-rs](https://github.com/EffortlessMetrics/pst-rs) | Outlook PST/OST with full encryption support |
| [hl7v2-rs](https://github.com/EffortlessMetrics/hl7v2-rs) | HL7 v2 parser, validator, generator |

## Development Infrastructure

| Repo | What it does |
|------|-------------|
| [uselesskey](https://github.com/EffortlessMetrics/uselesskey) | Deterministic cryptographic test fixtures for Rust |
| [shipper](https://github.com/EffortlessMetrics/shipper) | Resumable, backoff-aware publishing for Rust workspaces |
| [demo-swarm](https://github.com/EffortlessMetrics/demo-swarm) | Claude Code SDLC template for review-ready PRs |
